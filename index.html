Questions Answered

What AI music platforms do these prompts work with? +
Prompt Savant prompts are optimized for all major AI music generation platforms including Suno, Udio, and others. The Tagged Modular (Style B) format is particularly effective across platforms.
What's the difference between the tiers? +
All tiers access the same codex-grade library at different depths. Free gets 1 prompt per genre (50 total). Vault gets 40 per genre (2,050 total). Codex gets all 200 per genre (10,050 total) — the complete VP I/O library.
Are these one-time purchases? +
Yes. Both the Vault ($15) and Codex ($50) are one-time purchases. Pay once, access yours forever. No subscriptions, no recurring charges.
How do I access my upgrade after purchasing? +
After purchase you'll receive an access code by email. Enter it in the app under "Redeem Code" and your tier unlocks instantly.
What is VP I/O Variant Promptr? +
VP I/O is the full AI music platform that Prompt Savant is built around. It's currently in development. When it launches, Prompt Savant will function as an integrated plug-in — and VP I/O subscribers will get Prompt Savant access included in their tier upgrades.
Do I need to create an account? +
No account needed to use the free tier. Just open the app and start. Paid tiers are unlocked via access code — no login required.
